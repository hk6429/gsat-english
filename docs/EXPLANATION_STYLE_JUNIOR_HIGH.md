# 學測英文解析：國中生友善寫作規格

## 目標讀者

- 以 13–15 歲、具備國中英文基礎的學生為準。
- 用繁體中文與台灣教學用語；句子短、步驟清楚。
- 學生看完要能回答三件事：線索在哪裡、為什麼選這個、其他選項錯在哪裡。

## 不可變動範圍

- 每位撰寫者只可修改被指定檔案中的 `explain` 欄位。
- 不得修改題幹、文章、選項、答案、題號、分類、標籤、統計或題目順序。
- 不得改動 `data/bank.js`；該檔由主代理最後統一產生。
- 解析只能依題目與文章作答，不得捏造題目沒有提供的人物、數字、事件或因果關係。

## 共通語氣與格式

- 第一段固定以 `<b>解題關鍵：</b>` 開始，先指出題目中的關鍵字、轉折、因果或定位句。
- 接著用 `<br>` 分行說明各選項。四選一題原則上四個選項都要解釋。
- 正確選項要寫「意思＋放回句中的合理性」；錯誤選項要寫「意思或功能＋不符合哪個線索」。
- 最後可用一句「把答案放回去」整理完整語意，讓學生確認。
- 避免「顯然」「很簡單」「只要看就知道」等容易讓學生挫折的說法。
- 若使用「關係代名詞、分詞構句、假設語氣」等術語，立刻補上白話解釋。
- 不寫空泛句子，例如「依文意可知」「其他選項不合」；一定要說出具體文意。
- 不要求逐字翻譯整篇文章，但關鍵句須翻成自然、簡短的中文。

## 各題型寫法

### 詞彙與單句題

格式：

```html
<b>解題關鍵：</b>先說明句中的語意線索與正確搭配。<br>
(A) word：中文意思；為何適合或不適合。<br>
(B) word：中文意思；為何適合或不適合。<br>
(C) word：中文意思；為何適合或不適合。<br>
(D) word：中文意思；為何適合或不適合。<br>
把答案放回去：用中文說出完整句意。
```

- 若是固定搭配，要把搭配完整寫出並翻譯。
- 若選項本身沒有錯，只是不合這一句，要明確告訴學生「這個字可以使用，但不適合此處語境」。

### 綜合測驗與文法題

- 先讀空格前後至少一個完整句，指出連接詞、代名詞、時態、單複數或語氣線索。
- 各選項須說明在句中的功能；不要只貼文法名詞。
- 關鍵句要提供簡短中文句意。

### 文意選填

- 說明空格需要的詞性，以及前後文需要的意思。
- 正解需說明為何能和空格前後的字搭配。
- 至少比較最容易混淆的兩個干擾選項；若其他選項也可能造成誤解，再補充說明。

### 篇章結構

- 說明前一句談什麼、後一句接什麼，以及正解如何把兩邊接起來。
- 其他句子若屬於別段主題，要指出它比較適合放在哪一類內容旁，而非只說「不連貫」。

### 閱讀理解

- 先標示定位處，例如「第二段提到……」，並用中文重述證據。
- 主旨題要說明各段共同圍繞的核心，不可只抓單一細節。
- 推論題必須區分「文章直接說」與「由線索合理推出」。
- 四個選項逐一說明：符合證據、與原文相反、文章沒提到，或把局部誇大成全部。

### 多選題

- 每個選項獨立判斷，逐一標明符合或不符合的原文證據。
- 不可只列出答案字母。

## 長度與品質底線

- 一般四選一題的解析原則上至少 160 個中文字元。
- 文意選填、篇章結構等共用選項題，單題原則上至少 120 個中文字元。
- 解析必須包含具體線索與選項比較；達到字數但內容重複，仍視為不合格。
- 英文拼字、中文翻譯、答案字母與題幹語意都要自行複核。
