# 英文題庫分類規格

本站分類供練習、篩選與弱點分析使用，不是大考中心官方分類。題目原文、
選項與正式答案不因本站分類而改寫。

## 能力分類

| 代碼 | 名稱 | 使用範圍 |
|---|---|---|
| C1 | 詞彙能力 | 詞義辨析、語境搭配 |
| C2 | 語境與語法 | 綜合測驗、文法、文意選填 |
| C3 | 篇章組織 | 篇章結構與句子排序 |
| C4 | 閱讀理解 | 主旨、細節、推論、指涉與資訊排序 |
| C5 | 資訊整合 | 圖文整合、多文本整合與混合題 |

## 題型控制詞

- 詞彙題
- 文法題
- 綜合測驗
- 文意選填
- 篇章結構
- 閱讀測驗
- 混合題

## 標籤控制詞

- 詞義辨析、語境搭配
- 轉承語、語境選詞、邏輯關係、時態語意、篇章指涉、主旨連貫
- 文意選填、篇章結構
- 主旨判讀、語境推義、細節檢索、篇章理解、指涉判讀、資訊排序、推論判讀
- 圖文整合、多文本整合

新增分類詞前，必須同步更新資料驗證、前端篩選與本文件。分類調整不得連帶
改動題幹、選項、答案或官方統計。
