# 學測英文題庫

免費、免註冊的學科能力測驗英文科選擇題分類練習網站。

目前首批收錄：

- 115 學年度學測英文 47 題選擇題
- 單選題 46 題、多選題 1 題
- 47 題皆有官方答案、答對率／得分率、鑑別度與選項分析

歷史年份將依「官方試題 → 官方答案逐題比對 → 官方統計 → 分類 → 雙頁渲染驗收」的順序逐年回補。

## 主要功能

- 依年份、官方題型、能力分類、難度與鑑別度篩選
- 顯示大考中心官方答對率／得分率與鑑別度
- 作答後查看全體考生及低分組的各選項畫記百分率
- 錯題本、間隔複習、學習歷程與弱點分析
- 整回模考、教師選題與列印
- 題目問題回報

## 官方資料來源

- [大考中心學測歷屆試題](https://www.ceec.edu.tw/xmfile?xsmsid=0J052424829869345634)
- [115 學年度學測統計圖表](https://www.ceec.edu.tw/xmdoc/cont?sid=0Q056289672991900264&xsmsid=0J018604485538810196)

題目、答案、答對率、鑑別度與選項分析均依官方公開資料整理；缺少正式統計時不自行推估。解析為本站依題面撰寫的教學內容。

## 本機執行

這是以原生 HTML、CSS 與 JavaScript 製作的靜態網站。使用任一靜態檔案伺服器開啟專案根目錄即可。

重新由已解析的官方 XLS 產生題庫與統計：

```sh
node scripts/build-data.mjs
```

## 資料結構

- `data/g115.js`：115 學年度題庫
- `data/bank.js`：前端載入的合併題庫
- `data/option-stats.js`：官方全體／低分組選項畫記率
- `img/115/`：官方題圖裁切
- `.sources/115/`：本機查核用官方原始檔，不推送 GitHub
