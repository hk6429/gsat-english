# 大學英文題庫

免費、免註冊的大學學測與指考英文科歷屆選擇題分類練習網站。

## 收錄範圍

- 學測：83～115 學年度，共 33 份一般試題
- 指考：91～110 學年度，共 20 份一般試題
- 合計 53 份年度卷、2,850 題選擇題
- 每題均對照大學入學考試中心正式題本與答案
- 大考中心有公開且可可靠擷取的 44 個年度，共 2,355 題另附答對率／得分率、鑑別度，以及全體與低分組的各選項畫記率
- 官方未公開或原始檔無法可靠擷取的統計維持空白，不自行推估

非選擇題不納入線上選項式練習。極少數官方公告的一題兩解會保留所有可接受答案，不會誤標為多選題。

## 主要功能

- 依考試別、年份、官方題型、能力分類、難度與鑑別度篩選
- 作答後查看官方答對率、鑑別度及選項分析
- 錯題本、間隔複習、學習歷程與弱點分析
- 整回模考：學測 100 分鐘、指考 80 分鐘
- 教師選題、列印與 Word 匯出
- 題目問題回報與獨立查題頁

## 本機執行

這是以原生 HTML、CSS 與 JavaScript 製作的靜態網站。使用任一靜態檔案伺服器開啟專案根目錄即可。

```sh
npx serve .
```

重新合併各年度題庫並掛載官方統計：

```sh
npm run build:data
```

執行結構、統計、圖片與前端語法測試：

```sh
npm test
```

逐年度核對正式答案來源：

```sh
npm run validate:official
```

## 資料結構

- `data/g83.js`～`data/g115.js`：學測各年度題庫
- `data/z91.js`～`data/z110.js`：指考各年度題庫
- `data/bank.js`：前端載入的合併題庫，由腳本產生
- `data/option-stats.js`：官方答對率、鑑別度與選項分析，由腳本產生
- `img/<年度>/`、`img/z<年度>/`：正式題本必要題圖
- `.sources/`：本機查核用官方原始檔，不推送 GitHub
